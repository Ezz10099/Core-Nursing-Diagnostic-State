# Medication Reference Format Standard

This file preserves the preferred medication-reference format for future Core Nursing Diagnostic work, even if the user does not remember or restate it later.

## File category names
Use these short names:
- **Routine CCU meds** — medications encountered during CCU internship hours / routine ward exposure.
- **Emergency trolley meds** — medications found or learned from the emergency trolley.

A medication may appear in both files if it is relevant in both contexts. Do not force each drug into only one category.

## Preferred medication entry structure
Use the same predictable order for every drug:

1. **DRUG NAME — trade/generic**
2. **Class:** concise pharmacologic class
3. **Palestine availability:**
   - `YES` when the drug/form is supported by Palestinian MoH / Essential Medicines / Palestinian product-registry evidence.
   - `WARD-REPORTED` when observed locally but not independently confirmed in those public Palestinian sources.
   - Do not require a separate Gaza-only public stock listing when Palestinian authorities already document the medication/form.
   - Exact current hospital stock must still be verified from the product/container in hand.
4. **Form & administration**
   - Relevant dosage form and route.
   - Preparation/reconstitution/dilution only when verified for the actual product or clearly identified official product labeling.
   - Distinguish IV push vs slow IV injection vs intermittent infusion vs continuous infusion.
   - Include critical administration time/rate only when it is clinically useful or safety-critical.
   - State when pump/regulator/burette/CVC genuinely matters; do not call a CVC mandatory when peripheral administration is acceptable.
   - Do not invent fixed bag volumes or local concentrations.
5. **Emergency / CCU use**
   - State the practical reason the medication is encountered in CCU/emergency care.
   - Keep this clinically focused rather than listing every licensed indication.
6. **Nursing considerations**
   - Use bullets, not one dense paragraph.
   - Include the common/action-changing checks, hold/escalate situations, important adverse effects, interactions, required monitoring, common administration mistakes, and reassessment points.
   - Omit obscure specialist trivia and exhaustive side-effect lists.
   - Label rare-but-serious red flags as rare instead of making them sound routine.
7. **WHY:** one short mechanism/rationale that helps remember the important practical rule.

## Presentation standard
- Large, phone-readable portrait layout.
- Clear bold headings exactly like the preferred newer emergency-trolley file.
- Let one drug use as much space as needed; **do not force two drugs per page**.
- Prefer short paragraphs plus bullets under `Nursing considerations`.
- Keep drug entries visually consistent so the learner can scan by heading.
- Preserve generic + trade naming together when a trade name is reliably known.
- Do not overdecorate. Clarity and retrieval speed are more important than visual novelty.

## Why this format is preferred
The learner can scan the same sequence every time:

**What is it? → Is it available/recognized in Palestine? → How is it given? → Why is it used here? → What must the nurse check/do? → Why does that rule make sense?**

This is preferred over older dense paragraph-style medication entries because it is faster to scan on a phone, easier to review repeatedly, and better aligned with internship bedside use, exams, and nursing-job interviews.

## Evidence rule
For time-sensitive medication facts, follow the project evidence policy: prioritize Palestinian MoH/Essential Medicines/product records for local identity and forms, and current authoritative sources such as AHA/ILCOR and official product labeling for emergency algorithms, administration, contraindications, warnings, and exact high-risk rates/doses. When sources conflict, use the newest applicable authoritative guidance and state the conflict rather than silently mixing recommendations.
